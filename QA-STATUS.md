## Known sandbox limitations
- `upload.wikimedia.org` is unreachable from this sandbox, so the four real JPGs are still not
  vendored here; the page falls back to the same licensed Commons originals via `onerror` /
  `data-fallback`. Run `pnpm fetch:images` on a network-enabled machine.
- `astro check` cannot run here: the checker's `@astrojs/astro2tsx` transform needs
  `@napi-rs/wasm-runtime`, which this hoisted install did not provide (the CLI then falls back to an
  interactive “install @astrojs/check?” prompt). Use the editor diagnostics or run `pnpm check` on a
  normal machine.

## Final release gate on a network-enabled machine
```bash
pnpm install

pnpm make:icons
rm -rf node_modules dist .astro
pnpm install --frozen-lockfile
pnpm check
pnpm build
pnpm selfcheck
```

After the first successful `pnpm install`, commit the pnpm-generated `pnpm-lock.yaml` before
production deployment. Do not hand-write it.
